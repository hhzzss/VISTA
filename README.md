# 基于局部 ESDF 滑动窗口的 B 样条轨迹优化及无人机自主搜索研究

基于 [RACER](https://github.com/hhzzss/RACER) 的单无人机自主探索研究工程，面向未知三维环境中的前沿驱动覆盖探索。项目研究局部 ESDF 更新范围、目标方向引导的轨迹截取，以及二者与 B 样条轨迹优化的耦合关系。

研究目标是在保持地图查询有效性、轨迹安全性和运动约束的前提下，评价局部计算能否降低建图与重规划负担，并改善探索完成时间、飞行距离和覆盖表现。

## 技术内容

| 方向 | 实现内容 |
| --- | --- |
| 局部 ESDF 更新 | 增加可配置的轴对齐计算窗口，在探索规划时更新窗口中心，并将范围裁剪到地图边界；地图仍保留完整体素缓冲区 |
| 方向引导轨迹截取 | 提供目标与方向接口、方向对齐的椭球轨迹采样函数，以及球形回退分支 |
| B 样条优化耦合 | 复用 RACER 的样条表示与主要代价，通过距离和梯度查询连接局部 ESDF 与轨迹优化 |
| 调试与可视化 | 提供地图窗口、目标方向、前沿与轨迹显示，以及单机探索配置 |

方向引导采样目前仍需完成默认探索链路接入和状态初始化验证。工程还包含点云聚类、EOHDT 分层排序和点云碰撞检测原型，接入状态见[扩展模块说明](swarm_exploration/PHASE2_SUMMARY.md)。具体代码位置与调用关系见[相对 RACER 的改动](docs/RACER_CHANGES.md)。

## 构建与运行

运行环境为 Linux、ROS Noetic 和 catkin，依赖 NLopt、PCL、Eigen、OpenCV、Armadillo 及外部 LKH。依赖安装路径、地图发布方式和已知运行限制见[构建与运行说明](docs/REPRODUCIBILITY.md)与[核验记录](docs/VALIDATION.md)。

```bash
mkdir -p ~/catkin_ws/src
cd ~/catkin_ws/src
git clone https://github.com/hhzzss/VISTA.git
cd ..
source /opt/ros/noetic/setup.bash
catkin_make
source devel/setup.bash
```

完成构建、加载工作空间并启动地图发布节点后，在不同终端运行 RViz 和单机探索节点：

```bash
# RViz
roslaunch exploration_manager rviz.launch

# 单机探索（另一个已加载工作空间的终端）
roslaunch exploration_manager single_drone_exploration.xml simulation:=true
```

## 后续改进计划

依据开题报告，后续工作围绕局部地图与轨迹优化接口展开：

1. **完善局部地图有效性管理。** 核查窗口中心、尺寸、边界和更新触发方式，处理新进入区域、未知区域、越界与过期数据；统一距离和梯度查询的有效性判断，检查窗口移动与 ESDF 更新之间的时序。
2. **完成方向机制与规划流程的衔接。** 明确方向来源及其作用于轨迹截取域的方式，将椭球采样接入实际研究链路；检查缺少有效引导轨迹、急转弯、窗口边界和零方向下的初始化、回退与恢复行为。
3. **核验 B 样条优化的地图接口。** 检查优化查询点是否位于有效地图域，结合完整样条及其导数检查障碍间距、速度、加速度和平滑性，分析局部范围变化对优化收敛与轨迹质量的影响。
4. **建立可复现的实验配置与采集流程。** 固定基线和消融开关，增加地图更新、规划调用、覆盖、资源与事件的结构化记录；通过短任务验证采集完整性、计时方式与离线复算结果，再开展正式实验。

## 测试与评价计划

以下为计划开展的验证工作，具体窗口参数、共同超时和运行协议由预实验确定。

### 对照与消融

| 配置 | 内容 | 比较目的 |
| --- | --- | --- |
| G0 | 原 RACER 框架 | 提供基线 |
| G1 | 在相同基础上仅启用局部 ESDF 窗口 | 通过 G1 与 G0 比较窗口作用 |
| G2 | 启用局部窗口与方向引导机制 | 通过 G2 与 G1 比较方向机制的额外作用，并与 G0 比较完整方法 |

各组保持探索前端、地图分辨率、传感器模型、样条目标与权重、运动限制和控制器一致。G1 与 G2 尽量保持相同体素预算和更新频率；若方向机制同时改变窗口尺寸或处理体素数，则补充等预算配置 G2-eq，区分方向作用与容量变化。

### 分层验证

- **地图模块：** 回放相同位姿、建图传感输入和引导序列，覆盖直线、急转弯与窄通道，比较首次和稳态 ESDF 更新耗时、处理体素数、距离误差、查询有效性及实际分配字节数。参考距离场从相同已知占据状态生成。
- **规划模块：** 固定地图、起终状态、控制点初始化和运动约束，比较优化器耗时、整体局部规划耗时、迭代或目标评估次数、接受率及轨迹约束；重点检查近障碍、边界、过期地图和无有效引导的情况。
- **闭环探索：** 计划在 ROS/Gazebo 仿真中设置三类场景：开阔空间与柱状障碍、办公室与走廊门洞、迷宫与死胡同及垂向结构，至少一类包含明显高度变化。每类确定 5 个配对任务，G0、G1、G2 分别运行，共 45 次正式任务。

正式任务统一覆盖评价分母，以首次达到 95% 覆盖、不可恢复失败或共同超时作为终止条件。各组采用相同场景、起点和实际生效的随机种子，轮换运行顺序并清空旧地图与节点状态，保留失败任务及终止原因。

### 指标与数据分析

| 评价维度 | 计划记录的指标 |
| --- | --- |
| 建图与规划效率 | 每次 ESDF 更新和局部规划耗时的均值、P95、失败调用，初始化成本、处理体素数与响应延迟 |
| 探索表现 | 首次达到 95% 覆盖的时间 T95、累计执行距离 L95，补充 T90、L90、最终覆盖率和覆盖曲线 |
| 轨迹与安全 | 规划/执行轨迹的最小障碍间距、速度与加速度峰值、平滑度、动态超限、碰撞、优化失败及异常退出 |
| 资源占用 | 地图实际分配字节数、规划进程 CPU 与 RSS，并区分规划、仿真和录制进程 |

采用轻量 rosbag、内部结构化统计、进程监测与运行元数据联合采集。模块耗时使用单调墙钟，探索过程同时保留 ROS 仿真时间、真实墙钟时间和实际实时因子。以任务为统计单位，报告五次原始值、均值、标准差和配对差值；未达到覆盖阈值的任务记录终止原因和共同预算下的覆盖表现。

在主实验之外，补充窗口尺寸、样条时间间隔和环境尺度实验，分析参数敏感性、适用条件与失败案例。上述测试用于判断收益及代价，不预设性能提升比例。
